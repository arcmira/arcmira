# Arcmira: YouTube Transcript Search

[Arcmira](https://arcmira.com) · [API documentation](https://arcmira.com/docs) · [OpenAPI](https://api.arcmira.com/v1/openapi.json)

TypeScript SDK for finding timestamped passages, following speaker appearances across channels, researching mentions and sponsors, and managing media monitors.

See the [SDK installation and usage guide](https://arcmira.com/docs/libraries) for setup.

The SDK provides typed clients for transcript search, channels, entities, recommendations, monitors and account access. Requests require an Arcmira account. Account tiers and usage limits apply. Premium transcripts and creator captions are distinct sources. Monitor mutations change account state. A paid read uses credits from your plan, then your on-demand budget.

This package contains the SDK. The Arcmira CLI is distributed separately with the [npm package](https://www.npmjs.com/package/arcmira).

Source and release history: [arcmira/arcmira](https://github.com/arcmira/arcmira).
